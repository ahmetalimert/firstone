# Geotechnical Engineering — Source Library

A list of reliable sources for refreshing geotechnical engineering knowledge before job applications and interviews. **This file is meant to grow:** add new sources under the right heading by following the conventions in [`../CLAUDE.md`](../CLAUDE.md).

**Legend**
- **Access:** 🟢 free / open access · 🟡 free to read, registration or paid certificate · 🔴 paid (book, standard, or membership)
- **Status:** ✔ checked online (date in brackets) · ◻ added from memory, so confirm the edition or link before citing it in an interview or report
